# המתנה (Hamtana)

תוסף ל-Claude Code. בזמן ש-Claude עובד על בקשה, מעל שורת הקלט מופיעה מודעה אחת קצרה בעברית.
על כל צפייה מקבלים 70% ממה שהמפרסם שילם.
מיועד לכל מי שעובד עם Claude בישראל: מפתחים, מעצבים, עורכי דין ובעלי עסקים. לישראלים בלבד.
התוסף פועל בלשונית Code באפליקציית Claude ובטרמינל.

האתר: https://hamtana.oronai.co.il

## התקנה באפליקציית Claude (הדרך הקלה)

מעתיקים את הפרומפט הזה ומדביקים אותו בשיחה בלשונית Code באפליקציית Claude:

```
התקן לי את התוסף "המתנה" ל-Claude Code:
1. מצא את קובץ ההפעלה claude. אם הוא לא ב-PATH, קח את הנתיב של התהליך שמספרו במשתנה הסביבה CLAUDE_PID.
2. בדוק את הגרסה עם claude --version. אם היא נמוכה מ-2.1.287, עצור ותגיד לי לעדכן את אפליקציית Claude.
3. הרץ: claude plugin marketplace add OronNessim/hamtana-plugin
4. הרץ: claude plugin install hamtana@hamtana
5. בסוף תגיד לי במשפט אחד לפתוח שיחה חדשה כדי שהתוסף ייטען.
```

מאשרים את הפקודות, ואז פותחים שיחה חדשה. חלונית "המתנה" נפתחת לבד, עם כפתור "התחברות".

## התקנה בטרמינל

```
/plugin marketplace add OronNessim/hamtana-plugin
/plugin install hamtana@hamtana
```

## מה התוסף רואה

- רואה: מתי Claude מתחיל ומסיים לעבוד, ואם המודעה נשארה על המסך 10 שניות.
- לא רואה: קוד, פרומפטים, תשובות של Claude, קבצים, פקודות או משתני סביבה.

כל אחד יכול לבדוק את זה:

```
claude plugin validate ./plugins/hamtana
```

## כיבוי

- `/hamtana pause` עוצר מודעות.
- `/plugin` (או בתפריט התוספים באפליקציה) מכבה או מסיר את התוסף.

המתנה לא קשורה ל-Anthropic. כל מודעה מסומנת "מודעה".
